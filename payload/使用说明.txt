直播录制剪辑中控台 · 完整离线运行环境版
========================================

首次使用：
1. 将 ZIP 完整解压到空间充足的磁盘，不要直接在压缩包预览窗口中运行。
2. 双击“启动直播录制剪辑中控台.bat”。
3. Python、程序依赖、FFmpeg 和 Whisper 本地语音模型均已随包携带，不会访问 Hugging Face 下载资源。
4. 记事本打开后，填写 GPT-5.5 主密钥；如需双路并行，再填写 GPT-5.4 第二密钥；GPT-5.4-mini 密钥作为自动备用线路。按 Ctrl+S 保存并重启中控台。
5. 也可在网页首页点击“填写模型密钥”。中转站地址已经预填，密钥只保存在本机。DeepSeek 仍是可选补漏模型。
6. 浏览器随后会打开 http://127.0.0.1:8876 。
7. 在首页新增直播间即可开始使用，管理序号会自动生成。
8. 全新安装时录制器会在保存第一个已启用直播间后自动启动；若还没有直播间，不会弹出手工输入网址窗口。

AI 管家：
1. 首页点击“AI管家”可本地播报任务状态、诊断模型重试/渲染异常，并生成脱敏诊断包。
2. 本地自检不需要模型密钥；增强问答和截图分析默认复用 GPT-5.5 主线路密钥，也可在“填写模型密钥”中另填管家专用密钥。
3. 当前中转站 GPT-5.5 支持视觉时，文字和截图可复用同一把密钥；视觉密钥留空即可。
4. 舍弃或恢复异常任务都必须再次人工确认；舍弃只停止处理，不会立即删除录像和转写。

以后更新：
1. 先关闭“直播录制剪辑中控台”的黑色窗口，避免打断正在进行的转写或渲染。
2. 双击“检查并安装更新.bat”，窗口会显示当前版本和 GitHub 可用版本。
3. 确认安装后，程序会先自动备份，再只替换程序代码；失败会自动回滚。
4. 直播间、API 密钥、数据库、录像、素材、模型和导出记录不会被更新覆盖。
5. 如需恢复上一版，可在中控台关闭时双击“回滚上一个版本.bat”。
6. 在线更新依次尝试 GitHub API、GitHub 公开直链和 jsDelivr CDN；三条线路都不可用时可使用离线更新补丁。

注意：
- 本包不包含原电脑的模型密钥、抖音 Cookie、直播间、录像、候选或数据库。
- 录制抖音需要 Cookie 时，请在 DouyinLiveRecorder_v4.0.7\config\config.ini 的 [Cookie] 区域填写新电脑自己的抖音 Cookie。
- 使用 GPT 或 DeepSeek 分析仍然需要新电脑能够联网访问相应 API；只有 Python 和本地语音模型不需要下载。
- 整个文件夹必须一起移动，不要只复制启动文件。
- 程序运行期间不要关闭黑色命令窗口。停止使用时可以关闭该窗口。
- 若启动失败，窗口会停住，并在同一文件夹生成 startup-error.log。
2026.09.01.7 模型线路说明：
- 中转站 Plus：gpt-5.6-terra 主力，请填写 Plus 分组密钥。
- 中转站 Pro：gpt-5.5 主力，请填写 Pro 分组密钥。
- DeepSeek 官方：第三主力；中转站产出由它补漏，DeepSeek 主选不重复补漏。
- 三条线路独立保护，某条线路 TLS 中断时会由其他健康线路接续，不再暂停整个队列。
- 更新后点击网页“填写模型密钥”，按备注填写并保存，然后重启中控台。
