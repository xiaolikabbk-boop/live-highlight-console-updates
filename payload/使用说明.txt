直播高光工作台 · 桌面应用版
========================================

首次使用：
1. 将 ZIP 完整解压到空间充足的磁盘，不要直接在压缩包预览窗口中运行。
2. 双击“启动直播录制剪辑中控台.bat”。
3. 程序会在桌面建立“直播高光工作台”快捷方式；以后直接双击该快捷方式即可。
4. 后台服务与录制器均静默运行，不再保留黑色命令窗口。工作台会在服务真正就绪后才打开，不会提前显示“无法访问”。
5. 在首页点击“模型与密钥”，填写中转站或 DeepSeek 官方密钥；可先逐条测试连接，再点“保存并重启生效”。密钥只保存在本机且不会在页面回显。
6. Python、程序依赖、FFmpeg 和 Whisper 本地语音模型均已随包携带，不会访问 Hugging Face 下载资源。
7. 在首页新增直播间即可开始使用，管理序号会自动生成。
8. 全新安装时录制器会在保存第一个已启用直播间后自动启动；若还没有直播间，不会弹出手工输入网址窗口。

旧版数据交接：
1. 从旧版直接点击“检查更新”属于原目录升级，不需要迁移数据。
2. 更新只替换程序文件；highlight_service\data、录制目录、数据库、直播间、候选素材、积压队列和已导出成片均保持原位。
3. 更新完成后会继续领取原队列中的任务，不会从头重新转写。
4. 模型密钥既可以原样保留，也可以在新版“模型与密钥”中重新填写和测试。

AI 管家：
1. 首页点击“AI管家”可本地播报任务状态、诊断模型重试/渲染异常，并生成脱敏诊断包。
2. 本地自检不需要模型密钥；增强问答和截图分析默认复用 GPT-5.5 主线路密钥，也可在“填写模型密钥”中另填管家专用密钥。
3. 当前中转站 GPT-5.5 支持视觉时，文字和截图可复用同一把密钥；视觉密钥留空即可。
4. 舍弃或恢复异常任务都必须再次人工确认；舍弃只停止处理，不会立即删除录像和转写。

以后更新：
1. 在桌面工作台首页点击“检查更新”。有正在处理的单条任务时，等待该条完成后再安装。
2. 确认安装后，程序会先自动备份，再只替换程序代码；失败会自动回滚。
3. 更新期间桌面窗口会短暂断开，后台恢复后页面会自动重连，不会重复打开窗口。
4. 直播间、API 密钥、数据库、录像、素材、模型和导出记录不会被更新覆盖。
5. 如需恢复上一版，可在中控台关闭时双击“回滚上一个版本.bat”。
6. 在线更新依次尝试 GitHub API、GitHub 公开直链和 jsDelivr CDN；三条线路都不可用时可使用离线更新补丁。

注意：
- 本包不包含原电脑的模型密钥、抖音 Cookie、直播间、录像、候选或数据库。
- 录制抖音需要 Cookie 时，请在 DouyinLiveRecorder_v4.0.7\config\config.ini 的 [Cookie] 区域填写新电脑自己的抖音 Cookie。
- 使用 GPT 或 DeepSeek 分析仍然需要新电脑能够联网访问相应 API；只有 Python 和本地语音模型不需要下载。
- 整个文件夹必须一起移动，不要只复制启动文件。
- 若后台启动失败，会弹出错误提示，并在程序文件夹生成 startup-error.log。
2026.09.01.7 模型线路说明：
- 中转站 Plus：gpt-5.6-terra 主力，请填写 Plus 分组密钥。
- 中转站 Pro：gpt-5.5 主力，请填写 Pro 分组密钥。
- DeepSeek 官方：第三主力；中转站产出由它补漏，DeepSeek 主选不重复补漏。
- 三条线路独立保护，某条线路 TLS 中断时会由其他健康线路接续，不再暂停整个队列。
- 更新后点击网页“填写模型密钥”，按备注填写并保存，然后重启中控台。

2026.09.02.1 录制名单应用：
- 新增、编辑、启用/暂停、导入或批量添加直播间后，首页会明确显示“录制名单待应用”。
- 请在方便切段的时机点击“应用并重启录制服务”。当前录像会在此处分段，已完成分片仍会正常进入转写、模型分析和渲染流程。
- 录制器支持同时录制多个直播间；“待应用”不是并发数量上限，而是录制器需要重启才能读取新的直播间名单。

智能模型矩阵：
- Plus 和 Pro 分组各填写一把自己的密钥；默认每把密钥各调用 gpt-5.4、gpt-5.5、gpt-5.6-terra，共六条中转候选线路。
- 系统记录近期成功与耗时，优先持续使用成功率高、响应快的模型；单条异常会立即切到下一条健康线路，异常线路单独进入保护，不拖停同组其他模型。
- 某个分组若不支持其中一个模型，系统只会停用该单独槽位，其他模型照常运行；DeepSeek 的现有密钥和补漏设置无需改动。
- “多模型分析 · 2路”表示同时处理任务的并发数，不是模型总数；即使保持 2 路，六条模型候选和 DeepSeek 也都会参与智能选择。
